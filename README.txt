VISITOR ANALYTICS SETUP
------------------------
This project now includes js/analytics.js on every HTML page for Google Analytics 4.
1. Create/select the Vaarahi Interiors property in Google Analytics.
2. Create a Web data stream for the final .com domain and copy its Measurement ID (G-XXXXXXXXXX).
3. Open js/analytics.js and replace G-XXXXXXXXXX with the real Measurement ID.
4. Deploy the updated project to Vercel.
5. In Google Analytics, use Reports > Realtime to confirm visitors, then use Reports > Acquisition/Engagement for traffic and page views.

Important: A real cross-device visitor count cannot be safely hard-coded into a static HTML site. Google Analytics is used here so the visit data is genuine and can be viewed by the owner.
